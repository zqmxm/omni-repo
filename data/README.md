# data/ · 数据和素材放这里

## 这个文件夹是干什么的

放**数据文件、配置、素材**——比如图片、表格、样例数据、JSON 配置等。它是通用的"杂物抽屉"，不属于某个具体软件的数据都可以放这里。

## 里面现在有什么

目前是空的（只有一个 `.gitkeep` 文件，它的作用就是让这个空文件夹能被 GitHub 保留住，没有实际内容）。

## 以后放了文件怎么找

- 所有放这里的文件都用**中文名**，比如 `示例数据.xlsx`、`logo图片.png`
- 什么内容、给哪个软件用的，在文件名或旁边的说明里写清楚
- 新加了文件记得同步更新根目录的 `仓库地图.md`
