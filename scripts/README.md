# scripts/ · 工具脚本放这里（AI 干活用的工具）

## 这个文件夹是干什么的

放**给 AI 用的工具脚本**——备份软件到 GitHub、从 GitHub 下载文件、快速新建项目等。你一般不用直接运行它们，跟 AI 说话它就会自动调用。

## 里面每个文件是什么

| 文件 | 是干什么的（大白话） |
| --- | --- |
| `omni.py` | **备份总开关**——AI 用它把做好的软件和源码存到 GitHub，一条命令搞定 |
| `omni_lib.py` | 备份工具的"大脑"——真正干活的代码，处理上传、下载、版本编号 |
| `mcp_server.py` | 让 AI 能在**对话框里**直接帮你上传/下载文件，不用你打开 GitHub 网页 |
| `new_project.py` | **新建项目**用的——AI 用它快速建一个软件文件夹和基础结构 |
| `README.md` | 就是这份说明 |

## 生成的文件在哪里

这些脚本本身不产出给你的成品，它们帮你把成品**备份到 GitHub Releases**（去那里找）。下载时会自动用中文名保存到你指定的文件夹，比如 `透明橡皮擦 v0.0.3.exe`。
