# node/ · Node.js 程序放这里

## 这个文件夹是干什么的

放所有用 **Node.js** 写的程序——后端服务、前端工程、构建脚本等都放这里。一个软件一个子文件夹。

## 里面每个文件是什么

| 文件 | 是干什么的 |
| --- | --- |
| `index.js` | 最小示例——运行它打印一句问候，可照着它改 |
| `package.json` | 项目配置——记录名字、版本、怎么启动、怎么测试、依赖哪些库 |

## 怎么运行

```bash
cd node
node index.js     # 运行（package.json 里也定义了 npm start）
npm test          # 测试
```

## 生成的文件在哪里

Node 程序默认不生成文件。如果会导出文件，按命名铁律用中文名，并在软件的 README 里写清保存位置。依赖装好后会出现 `node_modules/` 文件夹——这是临时依赖目录，不会也不该上传 GitHub。
