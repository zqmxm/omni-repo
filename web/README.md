# web/ · 网页放这里

## 这个文件夹是干什么的

放所有**网页**——静态页面、单页小工具、可以在浏览器里打开的东西。一个软件一个子文件夹。

## 里面每个文件是什么

| 文件 | 是干什么的 |
| --- | --- |
| `index.html` | 示例首页——双击它就能用浏览器打开看效果 |

## 怎么打开

最简单：直接**双击 `index.html`**，用浏览器打开就行，不用装任何东西。

## 生成的文件在哪里

网页本身就在本文件夹里（`index.html`），改完刷新浏览器就能看到。如果要做需要安装的网页应用（带框架），会多出 `package.json`、锁文件等，那些是构建配置，AI 会在软件自己的 README 里写清楚。
