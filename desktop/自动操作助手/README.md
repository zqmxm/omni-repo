# 自动操作助手 · NeuralFlow

> 从"录制回放工具"升级为 **AI 视觉自动化助手**。用一句话下指令，AI 自己"看"页面、思考、逐步执行——全程在独立后台环境操作，不占用你的鼠标键盘。

## 核心能力

### ✦ AI 视觉内核（Computer Use）
- **感知**：抓取网页截图 + 可交互元素列表（或桌面软件 UIA 控件树）给多模态大模型
- **决策**：AI 输出结构化动作（打开/点击/输入/下载/上传/等待/完成）
- **执行**：通过 CDP / UI Automation 直接操作元素，不向系统发送键鼠事件
- **闭环**：每步执行后重新观察，形成"感知→决策→执行"循环，直到任务完成

支持服务商：**通义千问 VL**（国内直连，推荐）、**豆包视觉**、**OpenAI**、任意 OpenAI 兼容接口。

### ✦ 现代化界面
- 深色科技感 Web Dashboard（内嵌在 exe 中，无需额外安装）
- AI 对话式指令输入 + 实时步骤流（每步显示 AI 的思考与动作）
- 流程编排、运行日志、配置管理四个页面
- 双击 exe 自动打开浏览器访问本地控制台（127.0.0.1:18760）

### ✦ 保留兼容
- 旧版的前台键鼠录制、网页后台任务、桌面 UIA 操作函数都保留在源码中
- 旧版脚本 `录制脚本.json` 格式不变

## 使用方法

1. 双击 `自动操作助手.exe`，浏览器会自动打开 NeuralFlow 控制台
2. 进入 **设置**，选择 AI 服务商、填入 API Key、保存并"测试连接"
3. 回到 **AI 助手**，输入自然语言指令，例如：
   - `打开 example.com，找到下载按钮并下载文件到 D:/下载`
   - `搜索"AI 自动化"并把第一条结果的标题告诉我`
4. 点击 **启动**，实时观看 AI 一步步执行

> 桌面软件模式：切换到"桌面软件"，输入窗口标题关键词。AI 通过 UIA 读取控件树并操作按钮/输入框。

## 目录结构

| 文件 | 说明 |
|---|---|
| `src/ai.go` | AI 视觉内核：多模态客户端、页面观察、动作规划与执行闭环 |
| `src/server.go` | Web 服务后端：内嵌界面、配置 API、SSE 实时事件流 |
| `src/cdp.go` | 后台浏览器：WebSocket + Chrome DevTools Protocol（打开/点击/输入/下载/上传） |
| `src/uia.go` | 桌面软件后台控制：Windows UI Automation（含控件树导出给 AI） |
| `src/main.go` | 程序入口（启动 Web 服务）；旧 Win32 界面函数保留作兼容参考 |
| `src/web/index.html` | NeuralFlow 控制台界面（深色科技感 Dashboard） |
| `src/*_test.go` | 单元测试（AI 动作解析、多模态请求构造、配置） |

## 构建

```bash
# Windows（项目根目录执行）
go build -ldflags="-H=windowsgui -s -w" -o "dist/自动操作助手.exe" ./src

# 自检
go test ./src -v
```

## 依赖与隐私

- 零第三方 Go 依赖，全部使用标准库
- API Key 保存在 exe 同目录的 `neuralflow-config.json`，权限 0600，不上传
- AI 调用会向所选服务商发送页面截图与元素文本；如涉及敏感页面请谨慎
- 除 AI 接口外，所有数据都在本机处理

## 局限

- 网页自动化只对标准网页有效；验证码、需要登录的复杂流程可能需要人工介入
- 桌面软件需暴露 UIA 控件树；游戏、自绘画布等软件无法后台控制
- Web 控制台运行中无紧急停止按钮，请关闭程序停止
