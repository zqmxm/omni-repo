# 自动操作助手

一个 Windows 桌面小工具：**录制或配置一套操作，点「启动」后自动重复执行**。提供三种模式：

- **网页后台模式（推荐）**：用独立的无界面 Chrome/Edge 执行网页操作，不占用鼠标键盘
- **桌面软件后台模式（新增）**：用 Windows UI Automation 直接操作目标软件的按钮和输入框，不移动鼠标、不抢焦点、不发全局按键
- **前台录制模式（兜底）**：录制任意桌面软件的键鼠操作；运行时会占用键鼠

## 一、桌面软件后台控制（不占用鼠标键盘）

在「桌面软件后台控制」区域：

1. 填**窗口标题关键词**（如“记事本”“订单系统”），点「测试窗口」确认能找到
2. 填**控件名称**或**自动化ID**（可用 Windows SDK 的 Inspect 工具查看控件的 Name / AutomationId）
3. 按需添加动作：
   - **点击控件**：直接调用按钮的 Invoke 接口，不移动鼠标
   - **填写控件**：直接给输入框赋值，不发送按键
   - **启动程序**：填 exe 完整路径，先启动软件
4. 填循环次数，点「启动」或按 **F10**；**F11** 随时停止

**系统文件对话框也能控制**：弹窗标题通常是“打开”或“另存为”，把窗口标题填成“打开”，控件名称填“文件名:”，用「填写控件」写入完整文件路径，再用「点击控件」点“打开”按钮——这就是桌面软件的自动上传方式。

> 局限：只对暴露了标准控件的软件有效（Office、资源管理器、WinForms/WPF/Qt 常规界面等）。游戏、自绘界面、部分老软件可能不支持；这类软件请用前台录制模式。

## 二、网页后台模式（不影响你操作电脑）

在「后台任务」区域，按需要添加动作：

- **后台网址 + 「后台打开网址」**：打开目标网页
- **元素选择器 + 「后台点击」**：点页面按钮/链接（也可填按钮文字来点击）
- **元素选择器 + 输入文本 + 「后台填写」**：给网页输入框填内容
- **后台网址 + 保存目录 + 「后台下载」**：直接下载；同时填了元素选择器则变为“进网页→点下载按钮→等文件落盘”
- **上传文件 + `input[type=file]` 选择器 + 「后台上传」**：自动上传；可填提交按钮选择器自动提交
- **「+等待1秒」**：步骤之间等待

元素选择器是网页元素的 CSS 定位，如 `#download`、`a.download`。浏览器路径留空会自动检测 Chrome / Edge。

## 三、前台录制模式（会占用键鼠）

按 **F9** 开始录制（动作追加到列表末尾）→ 在任意软件里操作 → 按 **F9** 停止 → 点「启动」或按 **F10** 重复 → **F11** 紧急停止。

## 共同功能

动作列表显示每步中文说明；「保存脚本」/「加载脚本」把动作存到 exe 同目录 `录制脚本.json`，下次自动加载；「清空动作」重新开始。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `src/main.go` | 界面、前台录制/回放、三类后台任务调度 |
| `src/cdp.go` | 网页后台内核：WebSocket + CDP，打开网页、点击、填写、下载、上传 |
| `src/uia.go` | 桌面软件后台内核：PowerShell + UI Automation，点击/填写控件、启动程序 |
| `src/main_test.go` | 自检代码 |
| `README.md` / `VERSION` / `build.bat` / `build.sh` | 说明、版本、本地打包脚本 |

## 依赖与构建

- Go 1.21+，无第三方库；网页后台需要 Chrome 或 Edge，桌面后台需要 Windows PowerShell 5.1（系统自带）
- Windows：`build.bat`；Linux/Mac 交叉编译：`bash build.sh`
- CI：`.github/workflows/自动操作助手.yml`

## 边界说明

- 桌面后台不能控制不暴露控件的软件；网页后台不能控制普通桌面软件；两者都不处理验证码
- 系统文件对话框属于独立顶层窗口，按窗口标题定位即可控制
- 页面/软件界面结构变化后，选择器或控件名称需要更新
- 不要用于游戏或绕过任何平台的保护措施
