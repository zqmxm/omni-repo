# 自动操作助手

一个 Windows 桌面小工具：**录制或配置一套操作，点「启动」后自动重复执行**。提供两种模式：

- **后台模式（推荐）**：用独立的无界面 Chrome/Edge 浏览器执行网页操作，**不占用你的鼠标和键盘**，你照常办公、看网页都不受影响
- **前台录制模式（可选）**：录制任意桌面软件的鼠标键盘操作并重复；这种模式运行时会占用键鼠

## 后台模式怎么用（不影响你操作电脑）

1. 双击 `自动操作助手.exe`
2. 在「后台任务」区域填写信息，按需要添加动作：
   - **后台网址 + 「后台打开网址」**：打开目标网页
   - **元素选择器 + 「后台点击」**：点页面上的按钮/链接（也可不填选择器，在“输入文本”里填按钮文字来点击）
   - **元素选择器 + 输入文本 + 「后台填写」**：给网页输入框填内容
   - **后台网址 + 保存目录 + 「后台下载」**：直接下载文件；如果同时填了元素选择器，则改为“打开网页→点下载按钮→等文件落盘”
   - **上传文件 + 元素选择器（input[type=file]）+「后台上传」**：自动给网页上传文件；填了提交按钮选择器会自动点提交
   - **「+等待1秒」**：步骤之间等待
3. 循环次数填 **0 = 无限重复**（也可填具体次数），点「启动」或按 **F10**
4. 随时按 **F11** 或点「停止」终止

**元素选择器**就是网页元素的 CSS 定位，例如：`#download`、`a.download`、`input[type=file]`。在浏览器里按 F12 检查元素即可看到。

浏览器路径留空时会自动查找本机 Chrome 或 Edge；找不到时在界面里手动填写 `chrome.exe` / `msedge.exe` 的完整路径。

## 前台录制模式（会占用键鼠）

1. 按 **F9** 开始录制（动作会追加到列表末尾，不会清空已有后台动作）
2. 在任意软件里操作一遍
3. 按 **F9** 停止，点「启动」或按 **F10** 重复；**F11** 紧急停止

全局热键在切换软件后依然有效。速度取决于录制时每步之间的实际间隔。

## 共同功能

- 动作列表会显示每一步的中文说明
- 「保存脚本」/「加载脚本」：动作存到 exe 同目录的 `录制脚本.json`，下次打开自动加载
- 「清空动作」：重新开始

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `src/main.go` | 界面、前台录制/回放、后台任务调度 |
| `src/cdp.go` | 后台浏览器内核：WebSocket + CDP，打开网页、点击、填写、下载、上传 |
| `src/main_test.go` | 自检代码 |
| `go.mod` | Go 模块配置（工具链要求，不算软件名） |
| `VERSION` | 当前版本号，自动备份时加一 |
| `build.bat` / `build.sh` | 本地打包脚本 |
| `dist/自动操作助手.exe` | 本地成品（不入库，用 Release 分发） |

## 依赖与构建

- Go 1.21+，无第三方库；后台模式需要本机装有 Chrome 或 Edge
- Windows：`build.bat`；Linux/Mac 交叉编译：`bash build.sh`
- CI：`.github/workflows/自动操作助手.yml`（自检 + 打包 + Artifact）

## 边界说明

- 后台模式只能控制**网页**（Chrome/Edge 内核），不能后台控制普通桌面软件——那类软件只能通过前台键鼠模拟操作
- 后台模式不弹文件选择框：上传是直接把本地文件路径交给网页的 file input
- 网站如果有验证码、短信验证或强反爬机制，需要你人工介入
- 分辨率、页面结构变化后，CSS 选择器可能需要更新
- 不要用于游戏或绕过任何平台的保护措施
