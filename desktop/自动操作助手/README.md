# 自动操作助手 · NeuralFlow

> 用一句话下指令，软件自动"看"页面、找到元素、逐步执行——**默认使用本地智能引擎，无需 API Key、无需联网、完全免费**。全程在独立后台环境操作，不占用你的鼠标键盘。

## 核心能力

### ✦ 本地智能引擎（默认，开箱即用）
- **指令解析**：把中文指令按动词拆成有序步骤（打开 / 搜索 / 输入 / 点击 / 下载 / 等待 / 完成）
- **语义匹配**：每一步把目标与页面元素做匹配（精确 → 包含 → 同义词 → 字符二元组相似度），支持"登陆/登录""下载/立即下载"等说法差异
- **执行闭环**：通过 CDP / UI Automation 直接操作元素，不向系统发送键鼠事件；每步执行后重新观察
- **零成本**：纯标准库实现，毫秒级响应，结果可预期

### ✦ 云端多模态模型（可选）
复杂推理任务（如"把第一条结果的标题告诉我"）可在设置里切换到云端模型：**通义千问 VL**（国内直连）、**豆包视觉**、**OpenAI** 或任意 OpenAI 兼容接口。页面截图 + 元素列表发给模型，模型输出结构化动作。

### ✦ 现代化界面
- 深色科技感 Web Dashboard（内嵌在 exe 中，无需额外安装）
- 对话式指令输入 + 实时步骤流（每步显示匹配到的元素与匹配度）
- 流程编排、运行日志、设置四个页面
- 双击 exe 自动打开浏览器访问本地控制台（127.0.0.1:18760）

## 使用方法

1. 双击 `自动操作助手.exe`，浏览器自动打开 NeuralFlow 控制台
2. **什么都不用配置**，直接输入指令，例如：
   - `打开 example.com，点击登录`
   - `打开 bilibili.com，搜索"人工智能"`
   - `打开 https://xxx.com/file.zip 并下载`
   - `打开 数据网站，输入"北京"，点击查询，等 3 秒，点击下载`
3. 点击 **启动**，实时观看每一步执行

> 下载目录：在设置里指定；不填则默认 `用户目录/Downloads/NeuralFlow`。
> 桌面软件模式：切换到"桌面软件"，填写窗口标题关键词，通过 UIA 读取控件树并操作按钮/输入框。

### 本地引擎的局限
它理解的是"动作 + 目标名称"这类结构清晰的指令，不做开放式推理。如果某个目标在页面上找不到，它会等待一次后给出**最接近的元素和匹配度**，方便你换个说法重试。

## 目录结构

| 文件 | 说明 |
|---|---|
| `src/local.go` | 本地智能引擎：中文指令解析、元素语义匹配、步骤规划 |
| `src/ai.go` | 云端多模态内核 + 感知/执行闭环（页面观察、动作执行、规划器切换） |
| `src/server.go` | Web 服务后端：内嵌界面、配置 API、SSE 实时事件流 |
| `src/cdp.go` | 后台浏览器：WebSocket + Chrome DevTools Protocol（打开/点击/输入/回车/下载/上传） |
| `src/uia.go` | 桌面软件后台控制：Windows UI Automation（含控件树导出、默认按钮触发） |
| `src/main.go` | 程序入口（启动 Web 服务）；旧 Win32 界面函数保留作兼容参考 |
| `src/web/index.html` | NeuralFlow 控制台界面（深色科技感 Dashboard） |
| `src/*_test.go` | 单元测试（指令解析、语义匹配、规划闭环、AI 动作解析） |

## 构建

```bash
# Windows（项目根目录执行）
go build -ldflags="-H=windowsgui -s -w" -o "dist/自动操作助手.exe" ./src

# 自检
go test ./src -v
```

## 依赖与隐私

- 零第三方 Go 依赖，全部使用标准库
- 本地引擎模式下**所有数据都在本机处理，不联网**
- 切换云端模型时，API Key 保存在 exe 同目录的 `neuralflow-config.json`，权限 0600，不上传；页面截图与元素文本会发送给所选服务商，敏感页面请谨慎

## 局限

- 网页自动化只对标准网页有效；验证码、需要登录的复杂流程可能需要人工介入
- 桌面软件需暴露 UIA 控件树；游戏、自绘画布等软件无法后台控制
- Web 控制台运行中无紧急停止按钮，请关闭程序停止
