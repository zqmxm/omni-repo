# 自动操作助手

一个 Windows 桌面小工具：**先把你在电脑上的操作录一遍，之后点「启动」就能自动重复执行**。适合自动填表、重复点击、定时打开网址下载等场景。

## 功能

- **录制操作**：鼠标移动、左右键点击、滚轮、键盘按键，以及每一步之间的时间间隔
- **一键回放**：点「启动」或按 F10 开始自动执行；循环次数填 0 表示无限循环，直到手动停止
- **全局热键**：F9 开始/停止录制，F10 启动/停止回放，F11 紧急停止（切换到别的软件里也有效）
- **文本输入**：支持中文——填好文本点「添加文本动作」，回放时用剪贴板粘贴
- **打开网址**：填好网址点「添加网址动作」，回放时自动打开默认浏览器
- **脚本保存**：动作自动存到 exe 同目录的 `录制脚本.json`，下次打开自动加载

## 怎么用

1. 双击 `自动操作助手.exe`（Windows 10/11，64 位）
2. 按 **F9** 或点「开始录制」
3. 在任意软件里操作一遍（例如：打开浏览器 → 输入网址 → 点下载）
4. 按 **F9** 停止录制；可以用「保存脚本」留档
5. 在「循环次数」里填次数（0 = 一直重复），点「启动」或按 **F10**
6. 需要停下时按 **F11** 或点「停止」

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `src/main.go` | 全部源码：界面、录制钩子、回放引擎、脚本读写 |
| `go.mod` | Go 模块配置（工具链要求的文件名，不算软件名） |
| `src/main_test.go` | 自检代码（动作描述、脚本格式） |
| `VERSION` | 当前版本号，自动备份时加一 |
| `build.bat` | Windows 本地打包脚本 |
| `build.sh` | Linux/Mac 上交叉编译 Windows exe 的脚本 |
| `dist/自动操作助手.exe` | 本地打包出来的成品（不上传仓库，用 Release 分发） |

## 依赖与构建

- Go 1.21 或更新版本，无需第三方库、无需联网
- Windows 本地：`build.bat`
- Linux/Mac 交叉编译：`bash build.sh`
- CI：`自动操作助手.yml`（Windows 运行器，跑自检 + 出包）

生成的 exe 是单文件、无需安装，不含任何账号或密钥。

## 自检

在 Windows 上（或交叉编译时设 GOOS=windows）：

```
cd desktop/自动操作助手
go test ./src -v
```

## 边界说明

- 只支持 Windows 图形桌面；不支持 Linux / macOS 的可执行文件
- 录制的是屏幕坐标和按键，分辨率/窗口位置变化后需要重录
- 中文输入使用剪贴板粘贴，回放期间剪贴板内容会被替换
- 游戏反作弊软件可能会拦截模拟按键；不要用于游戏，也不要用于绕过任何平台的保护措施
- 无图像识别：不会“看懂”界面变化，只会按录制时的坐标和时间重复动作
