# 两个最新版 exe 的源码

本包只含**目前仍生效的两版**源码，旧版一律不含。

| 成品 exe | 校验值 | 对应源码 | 技术栈 |
|---|---|---|---|
| FileAreaRenamer.exe（132,973,947 字节） | CRC32 `A98C2A3A` | `FileAreaRenamer/app.py` v3.9 | Python + PySide6 |
| QuarkBatch.exe 稳定版 v2.1（88,064 字节） | CRC32 `3895089B` | `QuarkBatch/qb_stable.c` | 纯 C + Win32 API |

---

## 一、FileAreaRenamer（框选识别批量重命名）

### 文件
- `app.py` —— 主程序，2724 行。两套模式：PDF/Word 页面框选 OCR；Excel 按 A1/B1/C2 格子内容命名。含 .doc 内置解析、.xls/xlsx 读取、Word 原排版导出与内置重排、表格线擦除、框边半个字补全、拖入导入、重名「（1）」、批量重命名与撤销。
- `build.bat` —— 自己用 PyInstaller 重建的简化脚本。
- `launcher.c` + `_assemble.py` —— 构建脚本：把 Windows 版 Python 运行时、依赖库与 app 组装成**单个 PE 文件**。我交付的成品 exe 就是用这条链产出的；普通重建走 `build.bat` 即可，这两个不需要看。

### 自己重建（Windows 10/11）
```
pip install PySide6 pymupdf python-docx openpyxl xlrd==2.0.1 numpy onnxruntime pyinstaller pywin32
build.bat
```
产物在 `dist\FileAreaRenamer.exe`。

### 必须知道的差异
`build.bat` 打出来的 exe **不含内置 OCR 模型**。要走完整 OCR，需自备中文识别模型 `rec.onnx` 放到 `ocr\` 目录；已交付的成品 exe 是把模型一起塞进单文件的（所以有 132 MB）。PDF 文本层抽取、Excel 格子命名这些不依赖模型。

Word 要原排版预览时，机器上装 LibreOffice（免费）或 Office / WPS 效果最好；都没有时程序会自动走内置文本重排，仍可读可框选，但版式与 WPS 不同，**请按软件里的预览重新拖框**。

## 二、QuarkBatch 稳定版 v2.1（夸克扫描王批量入口/出口）

### 文件
- `qb_stable.c` —— 全部源码，1073 行，单个 C 文件，无头文件依赖。原生 Win32 GUI：队列、拖入、剪贴板（CF_HDROP）备料、浏览器打开登录、下载轮询归集改名（`原名_已处理.pdf`，重名「（1）」）、自动切下一个、兼容模式、CRC 显示与 `/verify`。

这版**不接管网页、不猜按钮文字、不开调试端口**，只做本地文件操作，所以官网改版不影响它。

### 编译（Linux 交叉编译出 Windows exe）
```
python -m pip install ziglang
python -m ziglang cc -target x86_64-windows-gnu -Os -Wl,--subsystem,windows -Wall qb_stable.c -o QuarkBatch.exe -lkernel32 -luser32 -lgdi32 -lcomctl32 -lshell32 -lole32 -lcomdlg32 -lshlwapi
```
Windows 本机用 MinGW-w64 / clang 指向 `x86_64-w64-windows-gnu` 亦可。只链接系统自带 DLL，目标机器不需装 Python、.NET 或运行库；要有 Edge 或 Chrome（Win10/11 自带 Edge）。

### 不含的内容
`QuarkBatch/app.py`（内嵌 Chromium 版 v1.0）和后来几版 CDP 全自动源码都是**已作废的中间版**，不在本包里。稳定版是从 v2.0 原生版改文案而来，没继承那套网页点击逻辑。

## 三、诚实交代

这些源码产出的 exe 做过静态校验（PE 结构、导入表、关键 API、中文字符串、CRC）和逻辑等价测试，**没有 Windows 实机运行验证**。全自动那几版反复出问题，根因就是我看不到夸克真实网页的按钮与上传框结构；稳定版把那层拆掉后才稳。

若要恢复全自动，需要夸克工具页的真实按钮文字和 `<input type="file">` 片段，改 `qb_stable.c` 后重新编译即可。
