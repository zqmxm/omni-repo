# 夸克扫描王批量处理

一个 Windows 桌面小工具，帮你**批量把 PDF 放进夸克扫描王、批量把处理好的 PDF 收回来**。它只是「入口」和「出口」，不改你的文件、也不替你操作网页。

> 一句话：网页里那几下还是你本人点，软件只管排队、备好下一个、把下载好的成品自动搬到你指定的文件夹。

## 这个软件干什么

1. 点「登录 / 打开夸克扫描王」→ 用系统 Edge / Chrome 打开官网，**你本人扫码或验证码登录自己的会员账号**。登录态留在浏览器里，扫一次以后不用再登。
2. 导入一批 PDF（也能直接拖文件夹进来）→ 选输出文件夹 → 点「开始」。
3. 软件自动把**当前这一个**文件放进剪贴板、在资源管理器里选中，你在网页里 `Ctrl+V` 粘贴 → 点「去手写 / 去水印」→ 点「下载 PDF」。
4. 下载一落地，软件**自动**把成品搬到输出文件夹、改名（默认 `原名_已处理.pdf`，重名加「（1）」）、自动切到下一个并备好下一个文件。重复第 3 步就行。

队列、备料、归集改名、切下一个全自动；「下一个 / 跳过当前 / 标记完成 / 停止 / 定位当前文件 / 打开输出文件夹」都有按钮。设置存在 `%APPDATA%\QuarkBatch\config.ini`。

## 边界（重要，写死）

- **不代登录、不读 Cookie、不注入 JS、不模拟点击、不抓接口、不绕过会员校验**。所有处理都由你自己的会员账号在夸克扫描王网页上完成。
- 软件**不做去水印、不做去手写**，它只搬文件。网页里那三下由你本人点。
- 因为不依赖网页按钮结构，**官网改版也不会让软件失效**。
- 本软件不含任何能绕过平台保护、移除他人版权内容的能力；请只处理你有权处理的文件。

## 文件都是干什么的

| 文件 | 说明 |
| --- | --- |
| `qb_stable.c` | **当前生效的稳定版 v2.1 全部源码**，纯 C + Win32 API，1073 行，单个文件无头文件依赖 |
| `VERSION` | 当前版本号 |
| `CHECKSUMS.md` | 成品 exe 的大小与校验值 |
| `历史版本/` | 已作废的中间版，留着备查，**不要拿去编译**：内嵌 Chromium 版 `内嵌网页版app.py`、`qb_lite.c`、`qb_auto*.c`（CDP 全自动尝试）、`qb_cdp*.h`、`launcher_q.c`、`_assemble_quark.py`、`qt_keep.json` |

## 怎么编译（Linux 交叉编译出 Windows exe）

```
python -m pip install ziglang
python -m ziglang cc -target x86_64-windows-gnu -Os -Wl,--subsystem,windows -Wall \
  qb_stable.c -o QuarkBatch.exe \
  -lkernel32 -luser32 -lgdi32 -lcomctl32 -lshell32 -lole32 -lcomdlg32 -lshlwapi
```

Windows 本机用 MinGW-w64 / clang 指向 `x86_64-w64-windows-gnu` 也行。只链接系统自带 DLL，**目标机器不用装 Python、.NET 或任何运行库**，Win10/11 自带 Edge 即可。编出来只有几十 KB。

## 怎么测试

导入 3～5 个 PDF，选输出文件夹，点开始；在网页里粘贴、点处理、点下载；确认成品自动改名归集、自动切下一个；再试跳过、标记完成、重名（1）、`QuarkBatch.exe /verify` 校验弹窗。

## 成品在哪下载

GitHub 本仓库 Releases 页 → **夸克扫描王批量处理-latest** → 显示名「夸克扫描王批量处理」的那个 exe。

历史交付时文件名叫 `QuarkBatch.exe`，内容完全一致；Release 附件实际文件名是 ASCII 的 `QuarkBatch-windows-x64.exe`，**内容没变，CRC 一样**。

## 关于「全自动」那几版（如实说）

`历史版本/qb_auto*.c` 是曾经尝试过的「登录后不用再碰浏览器」版本：开调试端口、用 CDP 接管已登录页面、自动塞文件和点按钮。反复失败，根因是拿不到夸克工具页真实的按钮文字和上传框结构，只能猜，官网一改版就点不到。稳定版 v2.1 把这一层整个拆掉，只留纯本地文件操作，才稳下来。

如果以后要恢复全自动，需要夸克工具页的真实按钮文字和 `<input type="file">` 片段，改 `qb_stable.c` 重新编译即可。

## 其他边界

- 成品做过静态校验（PE 结构、导入表、关键 API、中文字符串、CRC）和逻辑等价测试，**没有在 Windows 实机上跑过**。
- 成品是纯本地文件操作，**不接入 `build-manifest.json` 自动构建**，也没加 workflow；后续更新走 Release 覆盖。
