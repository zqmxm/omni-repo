# 批量替换助手 v3.1.1

纯本地、单文件：选一个文件夹，输入「原内容 → 替换内容」，一键批量替换 Word / Excel 文件里的文字和文件名。**不需要安装 Office / WPS，不联网，不依赖任何运行时。**

同时提供 **Windows 原生桌面窗口** 和 **跨平台命令行（Windows / Linux / macOS）** 两种用法，共用同一套替换引擎。

## 能做什么

- **批量替换文档内容**：Word/Excel 新旧格式全支持，多组规则按顺序链式生效；覆盖正文、表格、文本框、页眉页脚、批注、脚注、图表、SmartArt、文档属性
- **批量替换文件名**：文件名里的指定文字一起替换，扩展名不变
- **支持子文件夹**：可选是否递归处理
- **另存模式**：勾选后原文件一个都不动，结果写到指定目录并保持原有子目录结构
- **撤销**：可连续撤销最近 10 次操作，原地替换按字节级备份还原、另存产物自动清理
- **预览（CLI）**：`--dry-run` 只列出会改动哪些文件，不写入
- **并发处理**：最多 8 线程；UI 全程不卡（后台任务 + 消息回传）
- **实时日志**：每个文件替换了多少处、成功 / 失败 / 跳过都看得见

## 桌面版怎么用（Windows）

双击 `批量替换助手.exe`，**直接弹出原生桌面窗口**（标题「批量替换助手 v3.1.1 · 本地桌面版」）。不打开浏览器、不监听端口、不联网。

1. **① 选择文件夹**：点「浏览…」选目录，或粘贴完整路径
2. **② 替换规则**：打开就有 5 条预置规则 `AAAA`/`BBBB`/`CCCC`/`DDDD`/`EEEE`，直接改成你要的内容
   - 「替换为」留空的行**不参与替换**（避免误删），可点「删除」移除整行
   - 例：`北京` → `上海`、`2025` → `2026`
3. **③ 输出方式**（关键）：
   - **不勾选「另存为新文件」= 直接在原文件上修改**（默认）
   - **勾选** → 在下面「另存到…」选一个输出目录，原文件完全不动；结果与源目录结构一致，只产出确实发生改动的文件
   - 目标目录里已有同名文件时默认跳过不覆盖
4. 按需勾选「包含子文件夹」「替换文档内容」「同时替换文件名」
   - **只想改文件名，必须勾「同时替换文件名」**：默认只改文档正文，文件名里的关键字不会动。如果正文没找到、但文件名里有，日志会明确提示你勾这个框；底部统计也会把「跳过」数量准确显示出来
5. 点「开始替换」，下方日志实时显示结果
6. 改错了点「**↶ 撤销上次替换**」，可连续点多次往前撤销；用完直接关窗口

> 撤销记录保存在程序同目录的 `batchreplace-undo.json` 与 `batchreplace-backups/`。
> 若程序放在只读目录（如 Program Files），会自动改存到用户配置目录。删除这两个条目即可清空撤销历史。

## 命令行版（跨平台）

同一个源码树，`批量替换助手-CLI.exe`（Windows）/ `batchreplace`（Linux/macOS）是控制台程序。GUI exe 带参数时也会进入 CLI 模式，但它属于无控制台子系统，输出不一定能被终端捕获，**脚本与命令行场景请直接用 CLI 版**。

```bash
# 原地替换，直接改源文件
batchreplace --dir "D:\合同" --rule "北京=上海" --rule "2025=2026" --rename

# 另存：原文件一个都不动
batchreplace --dir "D:\合同" --save-as "D:\合同_新版" --rule "北京=上海" --rename

# 先预览，不写入
batchreplace --dir "D:\合同" --rule "北京=上海" --dry-run

# 撤销（可连续执行）
batchreplace --undo

# 脚本集成
batchreplace --dir "/data/docs" --rules '[{"from":"A","to":"B"}]' --json
```

| 参数 | 说明 |
|---|---|
| `--rule "A=B"` | 替换规则，可重复；`B` 里可以含 `=` |
| `--rules '<JSON>'` | JSON 数组或 `{"pairs":[...]}` |
| `--rules-file <文件>` | 每行 `A=B`（`#` 注释），或 JSON |
| `--save-as <目录>` | 另存；不指定即原地修改 |
| `--overwrite` | 另存时允许覆盖已存在的同名文件 |
| `--rename` | 同时替换文件名 |
| `--no-content` | 不替换内容（配合 `--rename`） |
| `--no-recursive` | 不处理子文件夹 |
| `--dry-run` | 只预览，不写入、不生成撤销记录 |
| `--undo` | 撤销上次操作（最多保留 10 步） |
| `--state <路径>` | 指定撤销记录文件，便于脚本隔离 |
| `--json` | 输出 JSON，便于程序解析 |

## 支持的文件格式

| 格式 | 说明 |
|---|---|
| `.docx` / `.docm` / `.dotx` / `.dotm` | Word OOXML，无需 Office |
| `.xlsx` / `.xlsm` / `.xltx` / `.xltm` | Excel OOXML，无需 Office |
| `.doc` | 内置 OLE2 + piece table 解析器，无需 Office/WPS |
| `.xls` | 内置 OLE2 + BIFF8 解析器，无需 Office/WPS |
| 其他 | 跳过（只处理上述格式） |

## 注意事项

- **替换前请自行备份**：默认原地修改，虽然提供撤销，重要文件夹仍建议先备份
- 无命中时源文件**字节完全不变**（不会为了"没匹配"而重写文档）
- 正在被 Word / Excel 打开的文件可能无法写入，会记为失败，关掉后重试
- 文件名冲突、损坏或加密文档会跳过并记录，不影响其他文件
- `.doc` 采用「重写正文」策略：文字准确替换，但局部字符级格式可能被统一
- 另存目录若位于源文件夹内，扫描时会自动跳过，避免自产自销

## 开发者信息

- **单 exe**：`CGO_ENABLED=0` + `-ldflags="-H=windowsgui -s -w"`，无 embed 资源、无 DLL 依赖、无 HTTP 服务，可随意拷贝
- **入口分流**：`src/main.go` —— 无参数走 `runApp()`（Windows 原生窗口），带参数走 `runCLI()`；非 Windows 无参数直接打印帮助
- **原生界面**：`src/ui_win.go`，纯 Win32 API + 系统标准控件；`main()` 用 `runtime.LockOSThread()` 固定 UI 线程
  - **绘制优化**：渐变背景预渲染到内存位图，`WM_SIZE` 时重建一次；`WM_ERASEBKGND` 直接返回 1，`WM_PAINT` 单次 `BitBlt` 双缓冲；主窗口加 `WS_CLIPCHILDREN`；布局按 DPI 换算（100 次全窗强制重绘实测 0.015s）
  - **控件 ID 一律显式赋值**：绝不用 `iota`，否则 const 块顶部增删一行就会让所有 ID 漂移
  - **不使用定时保活**：后台 goroutine 定时 `PostMessage` 会稳定制造「未响应」，已彻底移除
  - 「浏览」对话框放在 `runtime.LockOSThread` 独立 OS 线程，结果用自定义消息回传，避免模态循环重入 Go 回调死锁
- **核心层**（跨平台纯逻辑）：`types.go`（请求校验）、`engine.go`（扫描/并发/另存/改名）、`undo.go`（撤销栈与集中备份）、`cli.go`（命令行）
  - OOXML：`ooxml.go`+`docx.go`+`xlsx.go`；旧格式：`docparse.go`+`olewrite.go`+`xls.go`；ZIP 安全写回：`ziputil.go`
- **Web 控制台**（历史遗留）：`server.go` / `browser_*.go` / `pickfolder_*.go` / `web/index.html` 带 `//go:build webui` 标签，**默认编译完全排除**
- **自检**：`go test ./src -v`（37 个测试，含 18 个边界测试、真实 .doc/.xls 样本端到端验证）
- **构建**：`build.bat`（Windows 产出 GUI + CLI）或 `build.sh`（当前平台；`CROSS=1 bash build.sh` 交叉编译三平台）
