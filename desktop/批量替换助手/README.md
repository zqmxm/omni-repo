# 批量替换助手

一个 Windows 桌面小工具：选一个文件夹，输入要替换的内容，一键批量替换 Word / Excel 文件里的文字，同时批量替换文件名。

## 能做什么

- **批量替换文档内容**：支持 `.docx`（Word）和 `.xlsx`（Excel），输入多组「原内容 → 替换内容」，按顺序全部替换
- **批量替换文件名**：文件名里的指定文字也能一起替换（扩展名不变）
- **支持子文件夹**：可选是否连子文件夹里的文件一起处理
- **旧格式支持**：`.doc` / `.xls` 会通过你电脑上安装的 Microsoft Office 或 WPS 自动处理；如果电脑没装这些软件，旧格式文件会被跳过并在日志里说明，不影响新格式文件
- **一键执行、实时日志**：每个文件替换了多少处、成功还是跳过，都能看到

## 怎么用

1. 双击 `批量替换助手.exe`，直接弹出**原生桌面窗口**（不打开浏览器、不占用端口）
2. 点「浏览…」在弹出的系统对话框里选文件夹——**不用手动输入路径**，选完自动回填完整路径
3. 打开就有 5 条预置规则（`AAAA`/`BBBB`/`CCCC`/`DDDD`/`EEEE`），直接把它们改成你要替换的内容；「替换为」列填新内容
   - **「替换为」留空的行不会参与替换**（避免误删），需要删掉整行可点该行「删除」
   - 例如：`北京` → `上海`、`2025` → `2026`
4. 勾选「包含子文件夹」「同时替换文件名」（按需）
5. 点「开始替换」，窗口下方日志区实时显示每条结果（✔成功 / ✖失败 / ⏭跳过）

> ⚠️ **替换后无法撤销，也不会自动备份**。请先把重要文件夹复制一份留底，再执行替换。

## 支持的文件格式

| 格式 | 支持情况 | 说明 |
|---|---|---|
| `.docx` | ✅ 完全支持 | Word 新版格式，无需安装 Office |
| `.xlsx` | ✅ 完全支持 | Excel 新版格式，无需安装 Office |
| `.doc` | ⚠️ 需 Office/WPS | 自动检测本机软件后台处理，没有则跳过 |
| `.xls` | ⚠️ 需 Office/WPS | 同上 |
| 其他文件 | ⏭ 跳过 | 只处理上述格式的文件内容 |

## 注意事项

- 多组规则**按顺序执行**：比如先把「北京」换成「上海」，再把「上海」换成「南京」，最终结果就是「南京」
- 正在被 Word / Excel 打开的文件可能无法写入，会记为失败，关掉文件后重试即可
- 文件名替换如果遇到同名的目标文件，会跳过并记录，不覆盖已有文件
- 损坏或加密的文档会跳过，不影响其他文件

## 开发者信息

- 技术栈：Go 1.21 标准库，零第三方依赖；`archive/zip` + `encoding/xml` 处理 OOXML，PowerShell COM 处理旧格式；**纯 Win32 API（syscall）原生窗口**，无浏览器、无 HTTP 服务
- 界面：`src/ui_win.go`（原生窗口 + 控件 + 消息循环 + `SHBrowseForFolderW` 系统选文件夹对话框 + GDI 深色绘制），`src/ui_other.go`（非 Windows 空实现，便于 Linux 跑测试）
- 入口：`src/main.go` 调 `runApp()`；替换核心 `engine.go`/`docx.go`/`xlsx.go`/`legacy.go` 未改动
- 自检：`go test ./src -v`
- 构建 Windows exe：`bash build.sh`（输出 `dist/批量替换助手.exe`，`-H=windowsgui` 无控制台黑框）
- 旧的 Web 界面与本地服务代码保留在 `src/web/`、`src/server.go`，仅作历史参考，主程序不再使用
