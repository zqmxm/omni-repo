替

批量替换助手

批量替换 Word / Excel 内容与文件名 · 本地运行，不联网

① 选择文件夹 要处理的 Word / Excel 文件都放在这里

② 替换规则 「替换为」留空则该组不生效；可添加多组

⚠️ 替换后无法撤销。程序会自动保留 .nf-bak 备份以防写入失败，重要文件仍建议先自行复制留底。

③ 开始执行

准备就绪，选好文件夹、填好替换内容后点「开始替换」。
支持 .docx / .xlsx / .docm / .dotx / .xlsx / .xlsm / .xltx / .xltm / .doc / .xls（含宏文档）
纯本地解析，无需安装 Office 或 WPS，也不需要联网。旧版 .doc 会重写正文，字符级局部格式可能被统一。
